# Ассеты и источники

Проект собран **полностью из процедурных ассетов**, без загрузки файлов из интернета.
Это сделано осознанно, чтобы игра работала офлайн и оставалась лёгкой для 8 ГБ ОЗУ.

## 3D-модели

### Скачанные CC0-паки (Quaternius) — в `assets/models/`
- **Stylized Nature MegaKit (Standard)** → `assets/models/nature/` — деревья, сосны, кусты,
  камни, трава, растения, грибы (glTF + текстуры).
- **Ultimate Animated Animals** → `assets/models/animals/` — олень, лань, бык, корова, волк, лиса,
  осёл, лошадь, лама и др. (glTF со встроенными текстурами и анимациями Idle/Walk/Gallop/Death).
- **Universal Base Characters (Standard)** → `assets/models/characters/` — базовые гуманоиды
  (риг 65 костей). *В текущей сборке НЕ используются: у моделей T-поза и нет анимаций, поэтому
  аборигены остались процедурными.*

**Лицензия всех трёх паков: CC0 1.0 Universal (Public Domain).** Автор — Quaternius
(https://quaternius.com). Тексты лицензий — в исходных архивах (`License_Standard.txt`).

Загрузка ассетов с кэшем и fallback — `scripts/asset_library.gd` (`AssetLibrary`).

### Процедурные модели — `scripts/models.gd` (фабрика `Models`)
Строятся кодом из примитивов, если скачанного ассета нет, а также для объектов, которых
нет в паках:
- пальма, бочка, ящик, доска-мусор, лист, пластик, рыба;
- акула, абориген (в маске), лодка, хижина, костёр;
- плот (плиты, стены, пол, крыша, лестница, дверь, окно, забор, парус, руль, весло, якорь);
- мебель и станции (верстак, плита, очиститель, сундук, кровать, лампа, стол, полка, грядка).

Лицензия: собственный код проекта. Low-poly, до ~500 треугольников на модель,
единая мрачная палитра через общий кэш материалов (`Models.mat`).

## Звуки
Все звуки синтезируются кодом в рантайме в `autoload/audio_manager.gd`
(генерация `AudioStreamWAV` из процедурного сигнала: тон, шум, огибающая, кроссфейд для петель).
Внешние аудиофайлы не используются.
Перечень: шаги (трава/песок/дерево/камень), плеск и плавание, волны, ветер, чайки,
дождь, гром, удары по дереву/камню/плоти, крафт, сундук, еда, питьё, костёр,
скрип плота и двери, крюк, парус, акула (плавник/удар), аборигены (шаги/крик), удар по игроку,
барабаны, тревожный эмбиент (усиливается с уровнем тревоги), музыка меню.

## Текстуры
Не используются растровые текстуры — материалы плоские (`StandardMaterial3D`) с фильтром
Nearest. Это даёт стиль Lethal Company и экономит память. Интерфейс (шрифт, иконки, тема)
выводится с Nearest-фильтром, поэтому остаётся чётким при целочисленном масштабе.

## Шрифты и интерфейс
- **Pixelify Sans** (пиксельный шрифт с полной поддержкой кириллицы) — `ui/fonts/PixelifySans.ttf`.
  Лицензия **SIL Open Font License 1.1 (OFL)**. Автор — Stefie Justprince. Источник: Google Fonts
  (https://fonts.google.com/specimen/Pixelify+Sans).
- **Иконки интерфейса** (`scripts/ui_icons.gd`) нарисованы кодом как пиксельные изображения 16x16 —
  внешние наборы не используются. Сопоставление «id предмета → иконка» хранится в одном месте (UiIcons.ITEM_KEY).
- Общая тема интерфейса — `ui/theme.tres` (тёмные панели, янтарный акцент, единые размеры).
